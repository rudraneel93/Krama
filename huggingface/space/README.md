# Krama

Paste a column of numbers. Krama finds the rule it follows and shows every number that breaks it,
with the value it should have been. When there is no rule, it says so instead of guessing.

- **Try it:** paste your own numbers or pick an example.
- **Spot the error:** a quick game. Can you beat the engine?
- **Leaderboard:** [Krama BreakBench](https://huggingface.co/datasets/Rudraneel93/krama-breakbench) asks
  whether AI models see patterns that aren't there.

Full product (Excel add-in, API, Python): [getkrama.vercel.app](https://getkrama.vercel.app) ·
open-source clients: [github.com/rudraneel93/Krama](https://github.com/rudraneel93/Krama)
